# Trabajos del Máster en Programación Creativa

Repositorio público y colaborativo para organizar y compartir los trabajos realizados durante el máster. Está organizado por módulos y cada alumno tiene su propio espacio para publicar sus proyectos y ejercicios.

## Estructura

Cada módulo tendrá un README con su descripción o consigna. Dentro de la carpeta de cada alumno se guardan los trabajos correspondientes.

```text
modules/
└── 01-nombre-del-modulo/
    ├── README.md
    └── usuario-de-github/
        └── nombre-del-trabajo/
            └── README.md
```

## Cómo contribuir

1. Hacé un **fork** de este repositorio.
2. Cloná tu fork con **GitHub Desktop**.
3. Abrí el proyecto en **VS Code**.
4. Creá una rama para tu trabajo.
5. Añadí o actualizá tus archivos dentro de tu carpeta.
6. Guardá los cambios con un **commit** y subí la rama a GitHub.
7. Abrí un **Pull Request** hacia este repositorio para que podamos revisar e integrar tu trabajo.

No hace falta usar la terminal para seguir estos pasos: podés gestionar Git desde GitHub Desktop.

## Qué incluir en cada trabajo

Cuando sea posible, añadí un `README.md` dentro de la carpeta del proyecto con:

- Nombre y breve descripción del trabajo.
- Módulo al que pertenece.
- Herramientas o tecnologías utilizadas.
- Instrucciones para verlo o ejecutarlo.
- Enlace a una demo, si está publicada.

## Publicación

Este repositorio es público. Subí únicamente trabajos y recursos que puedas compartir públicamente, y añadí los créditos correspondientes a los recursos de otras personas.
